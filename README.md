## ⚡ 快速开始

```bash
git clone https://github.com/Zeon7744/jianzhu-saas.git
cd jianzhu-saas
npm install
# 或
pip install -r requirements.txt
npm run dev
```

---

## 🛠️ 核心功能

| 模块 | 功能 |
|------|------|
| **项目管理** | 工程进度、里程碑、任务分配 |
| **成本管控** | 预算编制、成本核算、超支预警 |
| **协同办公** | 文档共享、审批流程、消息通知 |
| **数据统计** | 进度报表、成本分析、风险预警 |

## 📁 项目结构

```
jianzhu-saas/

├── docs/               # 开发文档
```
